# 重なりの例外
# ふだんは、同じ年に2つの勢力の範囲が重なると、小さい方の勢力の土地として大きい方から切り取る
# (独立した国が旧宗主国の範囲に残っている、などの Cliopatria の重複を直すため)。
# その規則が合わない組をここに書く。名前は図鑑と同じ日本語名。年の範囲は省略できる。
#
#   勝つ側|負ける側|年の範囲   重なった土地を、大きさに関係なく「勝つ側」のものにする
#   全体=部分|年の範囲         その年は切り取らない(「部分」は「全体」の一部として重ねたまま)
#
# 海南島: Cliopatria では中華民国(台湾)の範囲に1950年以降も残っている
中華人民共和国|中華民国(台湾)|1950~
# クヌートは1028〜1035年にノルウェーも支配した
北海帝国(クヌート)=ノルウェー王国|1028~1035
# 神聖ローマ皇帝はイタリア王を兼ねた
神聖ローマ帝国=イタリア王国(中世)|962~969
