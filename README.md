# ごちそう地球儀

回せる地球儀(平面の世界地図にも切り替えられる)で国や都市を選び、豆知識を見られるアプリ。国クイズ(ひとり用)と、部屋コードで友達と遊ぶオンライン対戦がある。

## 表示モード

画面右上の「⋯」メニューで切り替える。地図の形(地球儀 / 平面)も同じメニューで選ぶ(その端末に保存)。

| モード | 内容 |
|---|---|
| 現代の地図 | 最初に開くモード。いまの国と都市、豆知識。国クイズと対戦もここ |
| タイムスリップ | 西暦1年〜2024年の世界史の地図を1年ずつ動かせる。勢力の図鑑と、世界史クイズ |
| ごちそう(特別) | 郷土料理と作り方の検索(以前の探検画面) |

URLの末尾に `#timeslip` / `#food` を付けると、そのモードで開く。

## 案内役(チュートリアル)

銀河義賊ラグ☆ジュアリ～が、ノベルゲームのように立ち絵を切り替えながら使い方を説明する。

- 初めて開いたときに「使い方を案内しようか?」と聞く。「聞く!」で基本の使い方とモードの紹介、「あとで」ならモードの紹介もお休みにする
- タイムスリップ・ごちそう・クイズ・対戦・歴史クイズ・平面地図は、初めて開いたときにそのモードを紹介する
- 「⋯」メニューの「使い方を聞く」でいつでも聞き直せる。モード紹介のオン/オフも同じメニュー
- 見た案内はその端末(ブラウザ)に保存する(localStorage の `gg-lag`。消すと初めての状態に戻る)。対戦の招待リンクから開いたときは出さない
- セリフは `src/app.js` の `const LAG = {` にある。1行が `[ポーズ, セリフ, { spot: 光らせる部分, do: 始めにすること }]`。ポーズは `point`(ここだ!)・`jaki`(ジャキーン!)・`douzo`(どうぞ!)・`good`(グッド)
- 立ち絵は `site/img/lag-*.webp`。4ポーズを並べた元画像から `python3 build/sprites.py 元画像 site/img` で切り出す(背景の灰色を透明にする)

公開ページは `site/` フォルダの中身だけで動く静的サイト。`main` ブランチに push すると Vercel が自動で公開し直す。

## 問題を追加する

`site/quiz.tsv` に行を足して push すれば、公開ページに反映される(ビルド不要)。GitHub の画面で直接編集してもよい。

タブ区切りで、1行目の見出しで列を判別する(列の順番は自由)。

| 列 | 必須 | 内容 |
|---|---|---|
| 問題 | ○ | 問題文 |
| 答え | ○ | 正解。別解は `/` で区切る(例: `日本/にほん/にっぽん`) |
| ジャンル | | 表示用のタグ(例: `歴史`、`料理`) |
| 難易度 | | 1〜5。空なら3 |
| 解説 | | 答えたあとに表示 |
| 答えの種類 | | 国名以外の答え(首都、都市、料理、人物など)の種類。空なら、答えが国名なら `国名`、都市名なら `都市`、それ以外はジャンルの最初のタグ(`人物`、`名所` など) |
| 場所 | | 地球儀が止まる場所。国名・都市名・`緯度,経度`(例: `53.5,108.0`)。見出しは `国`・`国名`・`関連国` でもよい。空でもよい(下を参照) |
| 選択肢 | | 4択のときの誤答を `/` 区切りで3つ。空なら同じ種類の答えから自動で選ぶ |

- 答えの種類が `国名` のとき、または答えが場所の名前と同じとき(例: 答えも場所も `バレンシア`)は、回答するまで地図上の名前を隠す。
- それ以外は場所の名前を出したまま出題する(例: 場所 `ケニア`、答え `ナイロビ`)。回転中の針の表示と問題カードにも場所名を出す。
- 場所が空の行は次の順で場所を決める: 答えが国名・都市名ならそこ → すぐ上にある「答えが国名の行」の国(ジャンルの地域タグが同じとき) → 問題文に出てくる国名・都市名 → 解説に出てくる国名・都市名。国ごとに「国名の問題、その国に関する問題…」と並べたシートならそのまま読み込める。
- 答えに読みを括弧で付けてもよい(例: `赤道ギニア（せきどうぎにあ）`、`日本（にほん/にっぽん）`)。括弧の外を答えとして表示し、読みでの回答も正解にする。
- 書き方の例は `site/quiz-template.tsv`。
- 場所が地図で見つからない行は読み飛ばし、クイズの「問題を追加」欄に行番号を表示する。

公開ページのクイズ画面の「問題を追加」から、スプレッドシートの行を貼り付けて試すこともできる(その端末だけに保存される)。

## 早応え形式

地球儀が止まると「てーん」と効果音が鳴り、すぐに問題文が読み上げるように1文字ずつ表示される。表示の途中でも回答できる。表示速度は ゆっくり/ふつう/はやい から選べる。効果音は地球儀右上の「効果音」で切り替える。

- ひとり用: 結果に「問題文の何%で回答したか」を表示する。
- 対戦: 制限時間は問題文を読み終わってから数える。得点は正解10点+読み始めからの速さに応じて最大10点。

## オンライン対戦

- Supabase Realtime のブロードキャストを使う(プロジェクト `ability-debate` を共用、データベースには書き込まない)。
- 接続先は `src/app.js` の `SB_URL` / `SB_KEY`(公開用の anon キー)。
- ホストの端末が出題と採点を行う。正解で10点、残り時間に応じて最大10点のボーナス。

## タイムスリップ(世界史)

- 年表のスライダーとボタンで1年ずつ(10年・100年単位でも)動かせる。▶で再生。
- 地図の勢力をクリックすると図鑑が開く(存続期間、その年の面積、首都・建国者・政治体制、人物、発明・文化、面積の移り変わり、現在の国でいうとどこか)。
- 図鑑の「興亡を再生」で、その勢力を追いかけながら年を進める。
- 「2つの年を比べる」で、地図の左右に別の年を表示する(仕切りはドラッグで動かせる)。
- 「現代の国境」で今の国境線と国名を重ねる。
- 年表の目盛りとピンは出来事。年表の横に「この年の日本」の時代(明治以降は元号と年)を出す。
- クイズは「地図から」(ある年に地図で示した地域を支配していた勢力)と「図鑑から」(建国者・首都・人物・発明など)。図鑑の問題で人物を答えると人物カードが手に入る(その端末に保存)。

### データ

境界線は [Cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria)(Seshat Global History Databank、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))を使う。線を簡略化し、海にはみ出した部分を Natural Earth の海岸線で切り落とし、日本語名を付けている(画面の注記にも出典と改変を書いている)。

Cliopatria では、独立した国の土地が旧宗主国の範囲にも残っていることがある(例: 1961〜2023年のフランスに、1963年に独立したアルジェリアが入ったまま)。ビルド時に、同じ年に2つの勢力の範囲が重なっていれば、小さい方の勢力の土地として大きい方から切り取る。この規則が合わない組は `data/history/overrides.txt` に書く。

`site/history/` に置く静的ファイルだけで動く(データベースは使わない)。

- `index.json`: 勢力の一覧・図鑑・出来事(gzip で約110KB)
- `c00.json`〜`c20.json`: 100年ごとの境界線(TopoJSON、gzip で1つ20〜300KB)。その世紀を表示したときに初めて読み込む

現代の地図だけを使う人はこれらを読み込まない。Vercel の無料プラン(Hobby)の転送量は月100GBなので、1人が全時代を見ても約2.5MBとして、月に数万人規模までは収まる。

### 作り直す

```
# Cliopatria を取得して展開(cliopatria.geojson.zip の中の geojson)
git clone --depth 1 https://github.com/Seshat-Global-History-Databank/cliopatria
unzip cliopatria/cliopatria.geojson.zip -d /tmp/clio
npm install
npm run history -- /tmp/clio/cliopatria_polities_only_v021.geojson
```

初回は海岸線での切り落としなどに15分ほどかかる(結果は `build/cache/` に保存され、2回目からは1分ほど)。重なりを切り取った組の一覧は `build/cache/overlap-report.tsv` に出る。

- `data/history/polities.tsv`: Cliopatria の勢力名 → 日本語名(教科書の表記)。同じ勢力を時代で分けるときは年の範囲を付けて複数行にする(例: 前漢 / 後漢、メロヴィング朝 / カロリング朝)。日本語名が同じ勢力は図鑑で1つにまとまる。未登録の名前があるとビルドが止まる
- `data/history/extra.txt`: Cliopatria にない勢力(倭、大ジンバブエ、コモロなど)や記録の抜けている年(イラク 2006〜2013年など)。境界はおおまかな多角形で、海にはみ出してよい
- `data/history/overrides.txt`: 重なりの例外(海南島は中華人民共和国、など)
- `data/history/labels.tsv`: 国名を置く本国の地点(植民地の方が大きい国で、国名が植民地に出ないようにする)
- `data/history/zukan.txt`: 図鑑の解説。書き方はファイル先頭のコメントを参照。クイズの「図鑑から」はこの内容から自動で作る
- `data/history/events.txt`: 出来事(年・場所・説明・関係する勢力)

## 料理・豆知識・地図を変える

`site/index.html` は次の手順で作り直す。

```
npm install
npm run map    # 地図データを作り直すときだけ(data/world.json)
npm run build  # data/*.txt → build/bundle.json → site/index.html
```

- `data/c1_asia.txt` などの国データ: `@ISO3 首都` の下に `- 料理 = 説明`、`* 豆知識`
- `data/cities.txt`: `#都市名|ISO3|緯度|経度` の下に同じ形式
- `data/extras.txt`: 台湾・香港などの地域
- `data/country_names.tsv`: 国連加盟国の日本語名・別名・地域
- `src/app.js`: 地球儀・平面地図の描画、シャッフル、検索、クイズ、対戦、タイムスリップ、案内役
- `src/app_head.html` / `src/app_body.html`: 見た目とHTML

地図は Natural Earth 1:50m(world-atlas)。国境線は実効支配線にもとづき、帰属に争いのある地域は斜線で表示する。
