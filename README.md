# ごちそう地球儀

回せる地球儀で国や都市を選び、郷土料理の作り方検索と豆知識を見られるアプリ。国クイズ(ひとり用)と、部屋コードで友達と遊ぶオンライン対戦がある。

公開ページは `site/` フォルダの中身だけで動く静的サイト。`main` ブランチに push すると Vercel が自動で公開し直す。

## 問題を追加する

`site/quiz.tsv` に行を足して push すれば、公開ページに反映される(ビルド不要)。GitHub の画面で直接編集してもよい。

タブ区切りで、1行目の見出しで列を判別する(列の順番は自由)。

| 列 | 必須 | 内容 |
|---|---|---|
| 問題 | ○ | 問題文 |
| 答え | ○ | 正解。別解は `/` で区切る(例: `日本/にほん/にっぽん`) |
| ジャンル | | 表示用のタグ(例: `歴史`、`料理`) |
| 難易度 | | 1〜5。空なら3 |
| 解説 | | 答えたあとに表示 |
| 答えの種類 | | 空なら `国名`。国名以外の答え(首都、都市、料理、人物など)はここに書く |
| 場所 | | 地球儀が止まる場所。国名・都市名・`緯度,経度`(例: `53.5,108.0`)。答えの種類が国名なら空でよい |
| 選択肢 | | 4択のときの誤答を `/` 区切りで3つ。空なら同じ種類の答えから自動で選ぶ |

- 答えの種類が `国名` のとき、または答えが場所の名前と同じとき(例: 答えも場所も `バレンシア`)は、回答するまで地図上の名前を隠す。
- それ以外は場所の名前を出したまま出題する(例: 場所 `ケニア`、答え `ナイロビ`)。回転中の針の表示と問題カードにも場所名を出す。
- 書き方の例は `site/quiz-template.tsv`。
- 場所が地図で見つからない行は読み飛ばし、クイズの「問題を追加」欄に行番号を表示する。

公開ページのクイズ画面の「問題を追加」から、スプレッドシートの行を貼り付けて試すこともできる(その端末だけに保存される)。

## 早応え形式

地球儀が止まると「問題」の効果音が鳴り、一拍おいてから問題文が読み上げるように1文字ずつ表示される。表示の途中でも回答できる。表示速度は ゆっくり/ふつう/はやい から選べる。効果音は地球儀右上の「効果音」で切り替える。

- ひとり用: 結果に「問題文の何%で回答したか」を表示する。
- 対戦: 制限時間は問題文を読み終わってから数える。得点は正解10点+読み始めからの速さに応じて最大10点。

## オンライン対戦

- Supabase Realtime のブロードキャストを使う(プロジェクト `ability-debate` を共用、データベースには書き込まない)。
- 接続先は `src/app.js` の `SB_URL` / `SB_KEY`(公開用の anon キー)。
- ホストの端末が出題と採点を行う。正解で10点、残り時間に応じて最大10点のボーナス。

## 料理・豆知識・地図を変える

`site/index.html` は次の手順で作り直す。

```
npm install
npm run map    # 地図データを作り直すときだけ(data/world.json)
npm run build  # data/*.txt → build/bundle.json → site/index.html
```

- `data/c1_asia.txt` などの国データ: `@ISO3 首都` の下に `- 料理 = 説明`、`* 豆知識`
- `data/cities.txt`: `#都市名|ISO3|緯度|経度` の下に同じ形式
- `data/extras.txt`: 台湾・香港などの地域
- `data/country_names.tsv`: 国連加盟国の日本語名・別名・地域
- `src/app.js`: 地球儀の描画、シャッフル、検索、クイズ、対戦
- `src/app_head.html` / `src/app_body.html`: 見た目とHTML

地図は Natural Earth 1:50m(world-atlas)。国境線は実効支配線にもとづき、帰属に争いのある地域は斜線で表示する。
